Overview

This lab introduces the difference between Traditional AI and Generative AI and explores how both can be used in the aviation industry.

Traditional AI mainly analyses existing data to make predictions, classifications, or decisions, while Generative AI creates new content such as text, images, summaries, announcements, and other responses.

Traditional AI + Generative AI

Aviation businesses can use both technologies together.

For example, Traditional AI can analyse weather, aircraft, crew, and airport data to predict a flight delay. Generative AI can then create a clear and professional message explaining the delay to passengers.

Traditional AI = Analyse and decide
Generative AI = Create and communicate

Retrieved Information vs Generated Information

Retrieved information comes from a specific and existing source, such as an airline website, airport system, or official government website.

Generated information is newly produced by an AI model based on learned patterns and the user's prompt.

In aviation, important information such as flight status, baggage rules, regulations, safety requirements, and passenger rights should be checked against current and official sources.

Responsible Use of AI

AI-generated information should not automatically be treated as verified information.

Aviation employees should review important AI-generated information because it may be outdated, incomplete, or incorrect. Current operational, safety, regulatory, baggage, and passenger information should be verified using reliable and official sources.

Key Learning

The main learning from this lab is that the business problem should be identified before selecting an AI capability or tool.

Different problems require different capabilities:

Flight-delay forecasting → Prediction
Complaint categorisation → Classification
Passenger option selection → Recommendation
Creating passenger communication → Generation
Finding current regulations or policies → Retrieval
